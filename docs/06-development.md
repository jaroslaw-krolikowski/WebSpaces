# 06 — Development

## Commands

```bash
npm install
npm run build      # bundle into dist/
npm run dev        # esbuild watch mode
npm run typecheck  # tsc --noEmit, strict
npm test           # matching tests, no browser needed
```

Load `dist/` through `chrome://extensions` → Developer mode → Load unpacked.

## Build

`build.mjs` bundles four entry points with esbuild and copies `src/ui/*.html`, `ui.css` and the
icons. It also writes `dist/manifest.json`, injecting the `oauth2` block when a client id is
available. esbuild does not typecheck — that is what `npm run typecheck` is for.

Icons are generated by `scripts/make-icons.mjs`, which contains a small hand-written PNG encoder
so the project needs no image dependency. Rerun it only if the icon design changes.

## Tests

`scripts/test-matching.mjs` runs on the TypeScript sources directly; Node strips the types. It
can only cover `src/shared/`, which is why that directory must never touch `chrome.*` at
runtime.

What the tests protect:

- cookie-to-realm matching in both directions (the `ESTSAUTH` case)
- preset discipline: shared hosts in, organisation-specific hosts out
- rule pattern normalisation and subdomain semantics
- extraction of the address carried through the gate redirect
- host-only cookies being written without a `domain` field

## What cannot be verified outside the browser

Everything that touches `chrome.*`: the DNR gate, cookie swapping, tab group adoption, context
menus, and every Drive call. Those need the extension loaded. When changing any of them, reload
the extension and check the service worker console at `chrome://extensions`.

The gate logs a line whenever it falls back to the simpler rule set, which is the first thing to
look for if isolation behaves oddly.

## Conventions

- TypeScript `strict`, plus `noUncheckedIndexedAccess` and `noUnusedLocals`
- No runtime dependencies, no framework, no CSS library
- Comments explain **why**; the what is visible in the code
- Any non-obvious platform behaviour gets a comment with the reason, because these decisions
  are expensive to rediscover
