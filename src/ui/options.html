WebSpaces

Containers built on Chrome tab groups. A container is a tab group with the same name.

Containers

Opening rules

An address matching a pattern goes to the given container without asking, including addresses on hosts that belong to no realm. A new rule also covers tabs already open.

A bare host means the whole site, subdomains included: example.com also catches www.example.com. You can paste an address straight from the address bar — https:// and a trailing slash are ignored. A star stands for any fragment (*.sharepoint.com), and a slash narrows the rule to a path (admin.microsoft.com/*).

Isolation realms

A realm is a set of hosts whose cookies collide between containers. Only those are swapped — hosts outside every realm work normally and are never frozen. The realms below are a starting point: edit them, delete them, add your own.

List only hosts shared across organisations, where cookies actually collide (id.atlassian.com, login.microsoftonline.com). Addresses whose name carries the organisation (acme.atlassian.net, acme.sharepoint.com) belong outside the realm — they do not collide, so they can run in several containers at once.
